# データセット

本プロジェクトが利用するデータセットと、選定理由・実データの詳細をまとめる。数値は本プロジェクトの調査時点（2026-08-10）に実データを取得して実測したもの。

## 辞書データ: EJDict

- リポジトリ: [github.com/kujirahand/EJDict](https://github.com/kujirahand/EJDict)（俗に「EJDict-hand」とも呼ばれるが、現在の正式なリポジトリ名は `EJDict` のみ）
- ライセンス: **CC0 1.0 Universal**（パブリックドメイン相当。法的な表示義務はないが、クレジットは礼儀として記載する）
- ダウンロード元: `src/` 配下に26個の見出し文字別ファイル（`src/a.txt` 〜 `src/z.txt`）。単一の `ejdict-hand-utf8.txt` のような1ファイル形式ではない点に注意。
  - 例: `https://raw.githubusercontent.com/kujirahand/EJDict/master/src/a.txt`
- 実測データ量: **約45,631行・約47,000見出し語**（見出し語カラムはカンマ区切りで複数表記を含むことがあり、分割後の見出し語ユニーク数として約47,000）。生テキスト合計で約3.9MB。
  - 巷では「約21万件収録」と紹介されることがあるが、これは誤り、または過去バージョンの話である可能性が高い。本プロジェクトでは実測値を正とする。
- フォーマット例（タブ区切り、`見出し語<TAB>訳語`）:
  ```
  'em	=them
  A level	〈U〉(大学入学検定試験の)上級試験 / 〈C〉上級試験科目
  A,a	〈C〉英語アルファベットの第1字 / 〈U〉(音階の)イ音,イ調 / 〈C〉《米》(学校で成績優秀を表す)A
  ```
- 訳語カラムの記法:
  - `/` … 語義（意味）の区切り
  - `;` … 同一語義内での言い換え区切り
  - `,` … 補足的な言い換え
  - `(...)` … 補足説明
  - `=X` … 別見出し語Xへの同義語参照（本文なし）
  - `〈C〉` / `〈U〉` … 可算/不可算
  - `{動}` `{形}` `{副}` など … 品詞タグ
  - `《米》` `《英》` `《俗》` `《文》` `《差別的表現》` など … 地域・レジスタ・注意タグ
- 見出し語カラムの記法: カンマ区切りで複数の表記ゆれ・関連語をまとめている場合がある（例: `A,a`）。データパイプラインではこれを分割し、それぞれ独立した見出し語として正規化・格納する（詳細は [docs/data-pipeline.md](./data-pipeline.md)）。

## 例文データ: Tatoeba (`eng_sentences`)

- プロジェクト: [Tatoeba](https://tatoeba.org/)（多言語例文コーパス、クラウドソーシング型）
- ライセンス: **CC BY 2.0 FR**（原著者のクレジットが必要。パブリックドメインのTanaka Corpusを一部起源とする）
- ダウンロード元（英語のみの言語別エクスポート、全言語をまとめた `sentences.tar.bz2` ではなく、こちらを使う）:
  - `https://downloads.tatoeba.org/exports/per_language/eng/eng_sentences.tsv.bz2`
- 実測データ量: 圧縮時約24.8MB、展開後約104MB、**約203万行（約203万文）**
- フォーマット（ヘッダなし、タブ区切り3カラム）:
  ```
  id<TAB>lang<TAB>text
  ```
  例: `1276\teng\tLet's try something.`
- 採用理由:
  - CC BY はCC BY-NC-SAと異なり**商用利用も許可**されており、本プロジェクトの用途（ポートフォリオとしての公開、将来的な用途変更の可能性）に制約が少ない。
  - Tatoebaは対訳ペア（`links.csv`）を提供しており、将来的に「例文の日本語訳も表示する」といった拡張がしやすい（本MVPでは使用しない）。

### ライセンス対応方針（クレジット表記について）

Tatoebaの利用規約上、文の再利用時には**原著者のクレジット**が求められる。ただし基本の言語別エクスポート（`eng_sentences.tsv`）にはユーザー名が含まれておらず、固定のクレジット文言テンプレートも規約上定められていない。そのため本プロジェクトでは以下の実務的な対応を取る:

1. アプリのフッターに常時クレジットを表示する: 「Example sentences © their respective authors, from the Tatoeba Project (tatoeba.org), licensed under CC BY 2.0 FR.」
2. プレビュー画面で表示する例文それぞれに、該当文のTatoeba上のページ（`https://tatoeba.org/en/sentences/show/{sentence_id}`）へのリンクを添える。当該ページには著者情報が表示されるため、個別クレジットへの導線を確保する。

これは法的助言ではなく、本プロジェクトとしての意図的な運用判断として記録する。

## 不採用: Leipzig Corpora Collection（English Sentences 100k）

検討したが不採用としたデータセット。

- 概要: ライプツィヒ大学が提供する多言語コーパス集。ニュース・Web・Wikipediaなどのジャンル別、10K/100K/300K/1M文単位でのサブセットが用意されている（例: `eng_news_2020_100K`）。実際の文章から抽出されているため文が自然で、語彙の網羅性も高い。
- 不採用理由: ライセンスが **CC BY-NC-SA**（非商用利用限定・継承）であり、本プロジェクトの用途（ポートフォリオとして公開し、将来的な用途変更の可能性もある）と相性が悪い。Tatoeba（CC BY、商用利用可）の方が制約が少なく、本プロジェクトの目的に適していると判断した。
- 将来的に「より自然な例文が欲しい」という要求が強まった場合は、非商用スコープに限定した上で再検討する余地はある。
